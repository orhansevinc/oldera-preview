GÖREV — TRUE WIDESCREEN / NATIVE BACKING-STORE RUNTIME:
Mevcut `ws01-runtime-build` branchinden devam et. Yeni WS numarası alma.

Kullanıcının gerçek 1298 clientı şu anda native 1024x768 backing store ile modern 16:9 browser viewportunda aspect-preserving letterbox olarak gösteriliyor. Hedef, klasik KO UI'yi yatay esnetmeden ve HTML ile yeniden yapmadan gerçek 16:9/fullscreen deneyimin teknik runtime yolunu tamamlamaktır.

1. SDL/Emscripten window/canvas creation, GL viewport/scissor, resize ve framebuffer/backing-store zincirini incele.
2. 1024x768 sabit varsayımını nerelerin tuttuğunu exact source evidence ile çıkar.
3. Gerçek browser build için config-driven/dynamic 16:9 backing resolution desteği ekle veya mevcut engine sınırları buna izin vermiyorsa exact blockerı kanıtla.
4. Hedef desktop örneği 1920x1080; ayrıca 1280x720, 1366x768, 1600x900 ve 1920x1080 acceptance matrix kullan.
5. Görüntüyü CSS stretch ile genişletme, crop ile HUD kesme, Three.js/fake renderer/fake HTML HUD kullanma.
6. Klasik KO UI coordinate system ve mouse hit testing bozulmamalı. Gerekirse native render resolution ile UI logical resolution ayrımını açıkça tasarla; WS43 pointer/layout invariantlarını tüket.
7. Browser fullscreen enter/exit ve resize sonrası GL viewport/framebuffer yeniden kurulumu güvenli olmalı.
8. Local 4:3 fallback'i bozma; runtime config ile 4:3 ve widescreen davranışını test et.
9. Build/runtime tests ekle ve mümkünse headed Chromium real-client smoke hazırla.
10. WS43'ün integration contractını tüket; gerekiyorsa WS43'e exact handoff yaz. STATUS.md ve INTEGRATION_PATCH.md güncelle.
